به پنل مدیریت تکنوپارس خوش آمدید ✦

از منوی کناری بخش موردنظر را انتخاب کنید. می‌توانید متن‌های برند را تغییر دهید، محتوا اضافه کنید، تصاویر/لینک‌ها را تنظیم کنید و در پایان از داده‌ها پشتیبان بگیرید. با ذخیره محلی و ابزار انتشار GitHub می‌توانید محتوا را به نسخه آنلاین منتقل کنید.

یادآوری

انتشار آنلاین در GitHub ✦

برای اعمال تغییرات برای همه بازدیدکنندگان، مخزن و شاخه سایت را مشخص کنید. توکن GitHub فقط هنگام انتشار پرسیده می‌شود و در مرورگر ذخیره نمی‌شود.
